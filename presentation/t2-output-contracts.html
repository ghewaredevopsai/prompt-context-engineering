Tier 2

Output contracts

An answer a person has to read is a draft. An answer a program can check is a step in a pipeline. The difference is one paragraph in the request — and it is the difference between a demo and something that runs on Tuesday without you.

4 slides · ~8 minutes Lab 2 follows · make it validate Trainer: Rajesh Gheware

Three shapes

Ask the same question three ways, get three different kinds of thing back

Free prose

There are 16 consignments
needing attention. The largest
group is MF-03 — eight booked
before cutoff, still unrouted.
Two need dimensions.

Checked by: a person, reading.

Delimited

MF-1003|MF-06|reprice
MF-1024|MF-01|call depot
MF-1034|MF-03,MF-04|hold
MF-1038|MF-06|reprice

Checked by: a regular expression, badly. Nothing tells you a field is missing.

A schema you supplied

{"generated_for": "2026-03-04",
 "exceptions": [
   {"consignment": "MF-1003",
    "codes": ["MF-06"],
    "action": "reprice"}],
 "total": 1}

Checked by: json.loads, then keys, then a closed set.

The contract is the longest of the three — between about two and six times the prose, depending on how much the model narrates. Prose is short because it groups — "eight are MF-03" — and throws the per-consignment detail away. JSON enumerates all sixteen and repeats the keys on every row. They are not two renderings of one answer; only one can be acted on per consignment. Machine readability is bought, not free.

Two measured runs on the practice report: prose 125 / delimited 169 / JSON 707, and prose 450 / delimited 226 / JSON 846. The JSON is largest both times; the multiple is 5.7x and 1.9x, and the prose-versus-delimited order swapped between them. Quote the range, never a single multiple, and ask the room for their ratios. An earlier version of this deck claimed the JSON was the shortest, which is simply wrong. The delimited middle column is also worth a moment: it looks structured, it is the one teams reach for first, and a missing field shifts every column silently. It fails quietly, which is the worst property a format can have.

The loop

When the check fails, you repair the request — not the answer

What the checker says

exceptions[2].codes has 'MF-07',
which is not one of the six
'total' says 9 but there are 7 rows

What it deliberately cannot say

Whether those are the right seven consignments. Whether the actions are sensible. Whether it understood the question at all.

Shape is a lower bar than correct — and it is the bar that decides whether a human has to be in the loop.

MF-07 does not exist. The closed set of six is in validate.py and the billing feed rejects anything else, so a hallucinated code is a rejected batch and somebody's morning. That is why the checker knows the set rather than just checking that codes is a list of strings.
